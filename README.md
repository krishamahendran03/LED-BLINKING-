# LED Blinking PCB Design

## Project Overview
This is my beginner-level PCB design project created using KiCad. The main objective is to design a simple LED blinking circuit and convert the schematic into a physical PCB layout.

## Tools Used
- KiCad – Schematic Capture and PCB Layout
- Electrical Rule Check (ERC)
- Design Rule Check (DRC)
- Gerber File Generation

## Project Workflow
1. Created the LED blinking circuit schematic.
2. Assigned footprints to electronic components.
3. Converted the schematic into PCB layout.
4. Performed component placement and PCB routing.
5. Completed ERC and DRC verification.
6. Generated Gerber and drill files for PCB manufacturing.

## Skills Learned
- Basic electronic schematic design
- PCB component footprint assignment
- PCB layout and routing
- Understanding ERC and DRC
- Gerber and drill file generation
- Basic PCB design workflow

## Project Outcome
Successfully completed my first LED blinking PCB design with zero DRC errors.
